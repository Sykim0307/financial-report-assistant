FinDecode 소개

이 앱은 무엇을 하나요?

증권사 리포트, 펀드 설명서, 경제 전망 보고서처럼 어려운 금융 문서를 붙여넣거나 PDF로 올리면, 금융 지식이 없어도 이해할 수 있도록 쉬운 말로 풀어드립니다.

무엇을 얻을 수 있나요?

  • 쉬운 요약 — 원문의 핵심 결론과 수치를 놓치지 않는 평이한 문장 요약
  • 키워드 설명 — PER, 콜옵션, 듀레이션 같은 전문용어를 감지해 원문 근거와 함께 쉽게 설명
  • 인사이트 — 원문에 근거한 시사점을 기회·리스크·참고로 분류해서 제시

어떻게 만들어져 있나요?

별도 서버 없이 순수 HTML/CSS/JS로 동작하는 정적 웹앱입니다. 분석 요청은 Supabase의 서버리스 함수(Edge Function)를 거쳐 Claude에게 전달되고, 결과는 Supabase 데이터베이스와 이 브라우저의 기록에 함께 저장됩니다. Claude API 키는 서버 쪽에만 있고 이 브라우저에는 전혀 내려오지 않습니다.

이런 용도로는 사용할 수 없어요

  • 투자 자문 — 구체적인 매수/매도 종목 추천
  • 사실 검증(팩트체크) — 리포트 원문 내용이 맞는지 확인하는 용도

분석 결과는 참고용이며, 투자 판단의 책임은 사용자 본인에게 있습니다.

리포트 입력

증권사 애널리스트 리포트, 펀드 운용보고서, 경제 전망 보고서, 실적 발표 자료 같은 금융 문서에 적합합니다. 텍스트가 선택되는 PDF를 올리거나(스캔본·이미지 PDF는 텍스트 추출이 안 됩니다), 원문을 직접 붙여넣어도 됩니다. 최대 4만자까지 분석돼요.
