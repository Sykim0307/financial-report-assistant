# 회의록 정리

회의 메모(음성 전사, 메신저 대화, 손으로 쓴 요약 등 비정형 텍스트)를 받아
결정사항 / 할 일 / 담당자를 표로 정리한다.

## 입력 확인

- `args`로 파일 경로가 주어지면 해당 파일을 읽는다.
- 파일 경로가 없으면 사용자가 대화에 붙여넣은 회의 메모 텍스트를 입력으로 사용한다.
- 입력이 무엇인지 애매하면 바로 물어보지 말고, 대화에서 가장 최근에 제시된 회의 관련 텍스트/파일을 입력으로 간주한다.

## 추출 규칙

메모를 읽고 아래 세 가지를 구분해서 뽑아낸다.

1. **결정사항** — 회의에서 확정/합의된 내용. "~로 하기로 함", "~확정", "~합의" 같은 표현이나,
   대안 논의 끝에 하나로 정리된 문장이 해당된다. 단순히 논의만 되고 결론이 안 난 내용은 결정사항에 넣지 않는다.
2. **할 일(액션 아이템)** — 누군가 앞으로 해야 하는 구체적 작업. "~하기", "~공유", "~검토" 등
   동작을 지시하는 문장에서 추출한다. 담당자와 기한이 메모에 명시되어 있으면 함께 뽑는다.
3. **담당자** — 할 일 옆에 이름/직책/팀이 명시된 경우 그대로 사용한다. 명시되지 않았으면 "미정"으로 표기하고
   추측해서 채우지 않는다.

기한이 메모에 없으면 "미정"으로 둔다. 같은 할 일이 메모에서 여러 번 언급되면 중복 없이 한 줄로 합친다.

## 출력 형식

CLAUDE.md의 작업 규칙(표는 마크다운 표로 작성, 결론을 먼저 제시)을 따른다.
회의록 정리 자체에는 계산 근거가 필요하지 않으므로, "근거" 절 대신 "메모에서 확인 안 됨" 항목만 누락 없이 표시한다.

출력은 다음 순서로 구성한다.

1. 한 줄 요약(회의 주제/일자를 메모에서 알 수 있으면 포함, 모르면 생략)
2. **결정사항** 표

   | 결정사항 | 비고 |
   |---|---|

3. **할 일** 표

   | 할 일 | 담당자 | 기한 |
   |---|---|---|

4. 메모에 결정사항이나 할 일이 전혀 없으면 해당 표는 생성하지 않고 "결정사항 없음" / "할 일 없음"이라고만 적는다.

## 주의사항

- 메모에 없는 내용을 지어내지 않는다. 담당자·기한이 불명확하면 "미정"이라고 쓴다.
- 회의에서 나온 참고용 잡담이나 배경 설명은 표에 넣지 않는다(결정사항/할 일이 아니면 제외).
- 금액이 언급되면 CLAUDE.md 규칙에 따라 억원 단위로 표기한다.
